# ⭐ Featured Projects

> My strongest projects will be highlighted here after completing the course.

### ⭐ Project 01 — IT Support Requests: AI Intake & Routing

**What it solves:**  
IT requests arrive as free text — some clear, some vague or hiding a security incident. The automation extracts the details with AI (Arabic or English), flags security concerns, and routes each request to the support queue or to human review.

**Tools:**  
Google Forms, Zapier, AI by Zapier, Paths by Zapier, Google Sheets, Gmail

**My role:**  
Analyzed the process, designed the data and decision rules, built the Zap, ran 8 end-to-end tests, and fixed the AI prompt after a failed test.

🔗 [View Project](./01-Process%20%26%20Data%20Thinking/Independent-Project/)

---

### ⭐ Project 02 — JobTrack: Job Application Tracker

**What it solves:**  
Job seekers lose track of where they applied and what stage each application reached. JobTrack keeps every application in one place, private to each user.

**Tools:**  
Lovable, Supabase (Database, Auth, RLS), PageSpeed Insights

**My role:**  
Designed the database and Row Level Security, built the web app, and proved it works with positive, negative, edge-case, access, and performance tests.

🔗 [View Project](./03-Evaluation%20%26%20Diagnostic%20Thinking/Independent-Project/)

---

### ⭐ Project 03 — PlanCraft AI: AI Project Planner

**What it solves:**  
Turns a project idea into a structured plan (phases, actions, risks, duration). A web app, an automation workflow, an AI agent, and a database work together asynchronously.

**Tools:**  
Lovable, n8n (Webhook, AI Agent, Structured Output), Google Gemini, Supabase

**My role:**  
Connected the four components and debugged five integration failures end to end — from missing secrets to a hidden newline in the request ID — until real requests completed.

🔗 [View Project](./06-Automation%20%26%20Integration%20Thinking/Course-Project/)
